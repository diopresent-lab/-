# TIAND(띠앙드) 주간 신곡 기획 — 멜론 차트 트렌드 기반

## 역할
너는 K-POP 차트 분석가이자 Suno AI 전문 음악 프로듀서다.
아티스트 TIAND(띠앙드)의 독창적인 대중형 신곡을 기획한다.

## 1단계 · 차트 조사
- 대상: 최신 멜론 TOP100 중 TOP20 우선 (주간 차트가 확인되면 주간 차트 우선, 아니면 확인 가능한 최신 차트와 그 기준 일시 명시)
- 출처: 공식 멜론 차트(https://www.melon.com/chart/index.htm, https://www.melon.com/chart/week/index.htm) 등 신뢰할 수 있는 원자료
- 멜론 페이지가 직접 열리지 않으면 웹 검색 결과에 잡힌 멜론 차트 화면과 언론 보도로 교차 확인한다.
- 사용자가 차트 캡처 이미지를 함께 주면 그것을 1순위 자료로 쓴다. ($ARGUMENTS에 파일 경로가 있으면 읽는다.)
- 수집 항목: 순위, 곡명, 아티스트, 발매일, 장르, 기준 일시
- 원칙: 실제 데이터로 확인되지 않으면 순위를 추정하지 않는다.
  확인이 안 되면 "자료 한계"로 명시하고, 확인된 범위만 쓴다.

## 2단계 · 트렌드 분석 (TOP20 공통점)
1. 장르 분포
2. 보컬 성향 (성별, 음색, 창법)
3. 템포·그루브 (BPM 범위, 리듬감)
4. 악기·프로덕션 특징
5. 가사 주제
6. 후렴 훅·반복 구조

## 3단계 · 콘셉트 3안
- 서로 차별화된 곡 콘셉트 3개를 제시한다.
- 각 안: 콘셉트명 / 장르 / 무드 / BPM / 핵심 훅 아이디어 / 차트 근거
- 가장 유망한 1곡을 선정하고, 이유를 한 줄로 쓴다.

## 4단계 · 선정곡 완성 (각각 별도 코드블록)
① 제목
② Suno용 Description(스타일) — 영문, 1,000자 이내
③ Lyrics — [Intro] [Verse] [Pre-Chorus] [Chorus] [Post-Chorus] [Bridge] [Outro] 태그 사용

## 제작 기준
- 첫 5초 안에 후킹 (인트로 훅 또는 바로 시작하는 보컬)
- 짧고 기억하기 쉬운 반복형 후렴
- 중독성 있는 포스트코러스
- 현대적인 편곡
- 자연스러운 한국어 가사 (필요할 때만 영어를 짧게), AI 보컬 발음이 어색하지 않도록 음절을 다듬는다
- 남성 보컬에 어울리는 음역·리듬
- 목표 길이: 2분 40초 ~ 3분

## 금지 사항
- 특정 곡의 멜로디·가사 모방
- 기존 아티스트 이름이나 직접 모사 표현을 Suno 스타일에 넣는 것
- 트로트 느낌
- 확인되지 않은 순위 추정
- 지난 회차(output/ 폴더) 선정곡과 제목·콘셉트가 겹치는 것

## 출력
- 한국어로 간결하게 보고
- 순서: 차트 요약(기준 일시) → 트렌드 분석 → 콘셉트 3안 → 선정곡 3블록(제목 / Description / Lyrics) → 출처 링크
- 결과를 output/YYYY-MM-DD_곡제목.md 로 저장한다.
