## 2. 트렌드 분석
- 1위곡은 팬덤·방송 없이 공감 가사와 숏폼 입소문으로 정상. 보컬을 Suno AI로 생성하고 기획·작사·디렉션은 사람이 담당.
- 제작진은 AI 보컬의 어색한 발음을 없애려고 가사 음절을 고치고 재생성하는 작업을 반복.
- '연애의 조건'은 팬이 만든 15초 편집 영상에서 시작해, 직관적 후렴·중독성 멜로디·댄스 챌린지·유쾌한 이상형 가사로 역주행.
- '퇴사할게여'는 직장인 공감 테마.
- 상위 8곡 대부분이 걸그룹·여성 보컬, 남성 솔로 부재 → 남성 보컬 띠앙드의 틈새.
- BPM·편곡 세부는 원자료에 없어 분위기 수준으로만 반영.

## 3. 콘셉트 3안
1. 「읽씹 금지」 ⭐ 선정 — 레트로 신스 댄스팝 / 경쾌·위트 / 118 BPM / "띵동" 보컬찹 + 휴대폰 제스처 챌린지
2. 「아직 소년인 채로」 — 어쿠스틱 팝 발라드 / 30·40대 공감 / 76 BPM / 1위곡 주제와 겹칠 위험
3. 「금요일 6시」 — 펑키 시티팝 / 직장인 해방감 / 110 BPM / 직장인 테마 선점됨

선정 이유: 남성 보컬 공백 + 숏폼 확산력 + 상위곡과 주제 비중복.

### ② Suno Description
```
Upbeat K-pop retro synth dance-pop, 118 BPM, starts instantly with a catchy pitched vocal-chop hook "ding-dong" like a phone notification, punchy four-on-the-floor kick, slap bass, bright 80s-inspired analog synths, funky guitar cuts, handclaps, playful witty mood, warm charismatic male tenor vocal, rhythmic talk-sing verses, light falsetto on pre-chorus, short repetitive singalong chorus, addictive chant-like post-chorus with vocal chops, half-time breakdown bridge, final chorus lift, clean modern polished mix, tight radio edit, about 2:50
```
